# Android Farm برای QA داخلی

پلتفرم on-demand برای اجرای Android/Redroid روی Ubuntu 22.04/24.04 و Coolify؛ با دادهٔ پایدار، پراکسی اختصاصی اختیاری (یا خروجی مستقیم میزبان)، ADB محلی، صف Redis، مخزن APK برای نصب مجدد، لاگ متمرکز Loki و مانیتورینگ همراه Alertmanager. ظرفیت بر اساس منابع واقعی سرور محاسبه می‌شود و روی ۷۰ دستگاه قفل نیست.

**مرجع واحد نصب و مدیریت: [راهنمای گام‌به‌گام فارسی](docs/GUIDE.fa.md).** از بخش «شروع سریع» همان راهنما شروع کنید؛ DNS، تنظیمات Coolify، نصب، اولین دستگاه، پشتیبان‌گیری و عیب‌یابی همگی در همان فایل هستند.

آدرس‌های انتخاب‌شده:

| بخش | آدرس |
|---|---|
| سامانه | `https://commex-box.com/` |
| کنترل دستگاه | `https://commex-box.com/d/num01/` |
| مانیتورینگ | `https://metrics.commex-box.com/` |
| Coolify موجود | `https://coolify.commex-box.com/` |

این‌ها تنظیمات مقصدند؛ انتشار کد، DNS یا سرور را خودکار تغییر نمی‌دهد. پس از آماده‌کردن DNS و توکن Coolify طبق راهنما، روی سرور `185.208.172.141` اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/mjpouladi/AndroidFarm/main/install.sh -o install-android-farm.sh
sudo bash install-android-farm.sh --domain commex-box.com --admin-user mjpouladi --set-admin-password
```

نصب‌کننده رمز جدید را دو بار با ورودی مخفی می‌پرسد و حساب ورود فارم و مدیر Grafana را هماهنگ می‌کند؛ رمز را در فرمان ننویسید. ساخت پروژه، Compose، ENV، استقرار و فعال‌سازی API، CLI و Worker خودکار است. دامنهٔ پنل در نصب تازه همان دامنهٔ اصلی است؛ نصب‌های قبلی تنظیمات ذخیره‌شده را حفظ می‌کنند. برای تغییر پنل نصب قبلی، گزینهٔ `--console-domain commex-box.com` را نیز بدهید. حالت IP همچنان اختیاری است.

کنسول وب به API میزبان متصل است: وضعیت و منابع واقعی، ثبت/آزمون پراکسی یا انتخاب خروجی مستقیم، ساخت ترتیبی دستگاه با APK تأییدشده، روشن/خاموش/راه‌اندازی مجدد، بررسی IP، پشتیبان‌گیری، رویدادهای دستگاه‌ها و پیگیری درخواست‌ها. APK (مثلاً WhatsApp) را یک‌بار از بخش «مخزن APK» بارگذاری می‌کنید؛ میزبان آن را با aapt/apksigner بررسی، امضاکننده را pin و برای هر نصب بعدی استفاده می‌کند. پنل Docker socket یا فرمان shell آزاد در اختیار ندارد. اگر backend در دسترس نباشد، رابط خطا نشان می‌دهد و دادهٔ نمونه جای آن نمی‌گذارد. راهنمای واحد، آماده‌سازی کاتالوگ برنامه و نخستین دستگاه را نیز توضیح می‌دهد.

در تنظیمات پنل، اطلاعات ورود فارم/Grafana و رمز اتصال پراکسی را با تأیید رمز فعلی مدیریت کنید؛ وضعیت واقعی سرویس‌های مرکزی و دکمهٔ راه‌اندازی سرویس‌های نصب‌شده نیز در دسترس است. حساب SSH و Coolify در سامانهٔ خودشان مدیریت می‌شوند.

برای ارتقای نصب موجود، پس از توقف دستگاه‌ها `sudo bash /opt/android-farm/source/install.sh --domain commex-box.com` را اجرا کنید؛ برای تغییر حساب مدیر، همان دو گزینهٔ حساب بالا را اضافه کنید. راهنمای واحد، تشخیص اتصال API و تعمیر کنترل‌پلین را نیز پوشش می‌دهد. تست‌های محلی جای پذیرش TLS، Redroid، پراکسی و WebSocket روی Ubuntu مقصد را نمی‌گیرند.

این پروژه برای QA مجاز است و جعل IMEI/گوشی، پنهان‌سازی شبیه‌ساز، دورزدن Meta/Play Integrity یا ثبت‌نام انبوه را پیاده نمی‌کند. APK باید hash و signer تأییدشده داشته باشد.
